# Лабораторная работа №6

## Индивидуальный проект

Контроль качества перед публикацией: структурная проверка HTML, уникальность id, существование якорей, alt у изображений, наличие статически указанных локальных ресурсов, баланс фигурных скобок CSS, синтаксис main.js. Пять тестов проверяют, что контроль качества принимает корректный пример и обнаруживает типовые ошибки. Это не полная валидация HTML/CSS по стандартам и не проверка сетевой доступности внешних изображений.

## Пайплайн

1. validate: checkout, проверка сайта, node --check, unittest.
2. build: после успешного validate подготовить _site и загрузить артефакт github-pages.
3. deploy: после build настроить Pages и опубликовать артефакт.

В Pages перед первым запуском выбирается Source = GitHub Actions. Для deploy заданы pages: write и id-token: write. Дополнительные пароли и токены в файлах не хранятся.

В публикацию включаются только файлы сайта и изображения. Служебные скрипты, тесты и история Git не копируются в _site. В build-info.json фиксируются исходный commit и номер запуска.

## Проверка автоматического обновления

Сначала дождитесь успешного workflow и сохраните снимок сайта. Затем измените видимый текст в index.html, зафиксируйте изменение в main и дождитесь нового запуска с event=push. Сравните страницу по тому же публичному адресу и commit в build-info.json. Снимок локальной страницы не является доказательством обновления на хостинге.
